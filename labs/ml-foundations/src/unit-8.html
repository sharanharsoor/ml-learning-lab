    What does the number at a leaf mean?

    The count at the leaf describes the training emails that landed there. Its Spam score is Spam training emails at the leaf ÷ all training emails at the leaf. In this lesson, a score of at least 0.50 predicts Spam, including an exact tie. A validation email follows the same fitted questions and reads the leaf score.

    How is this different from changing the Unit 7 cutoff?

    A split checks one input measurement and sends each email to one branch. A cutoff on the final Spam score turns a model output into a class. The split questions are learned from training rows. Our model comparison uses a fixed 0.50 cutoff on both models’ output scores.

    How does the tree choose a question?

    A node’s Gini impurity describes how mixed its recorded labels are. If you draw two labels independently from the node’s class proportions, Gini is the chance they differ. A pure node has Gini 0. A node with a 50/50 mix of the two labels has Gini 0.5.

    1 · Measure the parent

    Gini = 1 − p(Spam)² − p(Legitimate)²

    Each class proportion uses the number of rows at this node.

    2 · Weight the two children

    Weighted Gini = (nYes ÷ n) × GiniYes + (nNo ÷ n) × GiniNo

    Here n is the current parent’s row count.

    3 · Find the reduction

    Gain = Giniparent − Weighted Gini

    Where do the numerical cutoffs come from?

    For each feature, sort its distinct values among the rows that reached this node. Try the midpoint between each pair of consecutive distinct values, so each candidate separates a different set of rows. If the neighbors are 10 and 11, the midpoint is (10 + 11) ÷ 2 = 10.5. Equal feature values travel together.

    In this fit, equal gain favors the exclamation-mark feature. Within one feature, equal gain favors the lower cutoff. These choices make the fit repeatable.

    How does this relate to entropy?

    Entropy measures the same question about label mix using H = −Σ p(class) × log₂ p(class). An absent class contributes zero. Entropy uses bits and Gini uses squared proportions. A tree that uses entropy still weights the children by their shares of the parent before subtracting from the parent’s impurity. The two criteria can choose different questions.

    When can a branch stop before the depth limit?

    A pure node already has one class. A mixed node also becomes a leaf if no eligible question improves Gini. The depth limit can turn a mixed node into a leaf even when another split could improve the training fit.

    How can two depths tie while making different predictions?

    At depth 4, E20 changes from Legitimate to Spam, which fixes a mistake. E54 changes from Spam to Legitimate, which creates a mistake. Across the validation fold, the extra level fixes 38 cases and introduces 38 other mistakes. Both depths get the same number right, even though they disagree on some emails.

    Why keep the inputs and the test emails the same?

    Different features can improve a model by giving it more information. Different test emails can make a benchmark easier or harder. Keeping the features and test emails the same lets us compare the fitted rules on a shared task.
