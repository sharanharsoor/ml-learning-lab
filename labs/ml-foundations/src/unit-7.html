Why do two names start with “true”?

True means the prediction agrees with the recorded label. False means they differ. Positive and negative name the predicted class. In this lesson, Spam is positive and Legitimate is negative. A false positive is a Spam prediction for a Legitimate email. A false negative is a Legitimate prediction for a Spam email.

Why does F1 use a harmonic mean?

F1 = 2 × precision × recall ÷ (precision + recall). A high F1 needs both precision and recall to be high. A small value pulls the harmonic mean toward it. The count formula avoids rounding the two parts first. F1 leaves true negatives out, so track the false-positive rate separately when false alarms matter.

What if there are no flagged emails?

Precision is undefined because TP + FP equals zero. The always-inbox rule still has zero recall here because there are recorded Spam emails and it catches none. Recall is undefined only when there are zero recorded Spam emails.

How does the false-positive rate differ from one minus precision?

Both use the false alarms in the numerator. At 50%, FPR divides 21 by the 625 recorded Legitimate emails, giving 3.36%. One minus precision divides those 21 by the 162 predicted Spam emails, giving 12.96%. The first asks what share of Legitimate mail was flagged. The second asks what share of flags were false alarms.

One cutoff gives one ROC point

The receiver operating characteristic (ROC) curve plots false-positive rate horizontally and recall vertically. At a validation cutoff of 50%, the point is (21 ÷ 625, 141 ÷ 386) ≈ (3.36%, 36.53%).

Start with a cutoff above every score. Nobody is flagged, so the curve begins at (0, 0). Lower the cutoff one distinct score at a time. Flag all emails with that score in the same step. The curve ends at (1, 1) when everyone is flagged.

ROC AUC measures ranking across the sweep

Area under the ROC curve equals the chance that a randomly chosen recorded Spam email ranks above a randomly chosen recorded Legitimate email, with half credit when the scores tie. Changing the cutoff moves the marker. AUC stays fixed because the underlying scores and the ranking stay fixed.

See a real win, loss, and tie
  • Win. Spam E1365 scores about 69.20%, above Legitimate E3027 at 51.21%. The pair earns 1.
  • Loss. Spam E17 scores about 48.66%, below that same Legitimate E3027. The pair earns 0.
  • Tie. Spam E8 and Legitimate E3383 both have 0% exclamation marks. The same fitted model gives both about 31.10%. The pair earns ½.

There are 386 × 625 = 241,250 Spam–Legitimate pairs on validation. Give one point for each win, half for each tie, then divide by the number of pairs. The area gives the same answer. In the sweep, a tied score group that includes both labels moves the point up and right together.

When should we read a precision–recall curve?

When Spam is rare, a small false-positive rate can still mean many Legitimate messages go to Spam. Precision shows how often a flagged message is actually Spam. A precision–recall curve plots precision against recall across the same cutoffs, so you can see that trade-off directly.
