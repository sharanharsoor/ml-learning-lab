ML Foundations course outline

Start with one bike-share forecast, fit a regression line, then turn an email measurement into a spam probability. Each unit has a worked example, a classroom check, and a runnable Python notebook.

Use Jump within unit to find an example or quiz while teaching. Quiz questions are visible on the page. Reveal the options, correct answer, and explanation in order.

  1. Make a first prediction

    Read one real bike-share record, estimate the rental count, and measure the miss.

  2. Python and Colab

    Run a cell, read a table, filter past hours, and reproduce the estimate.

  3. Understand the data

    Check data types and quality, read a chart, and calculate center and spread.

  4. Test on unseen data

    Separate training, validation, and test data. Compare a baseline with an honest forecast.

  5. Linear regression

    Fit a line to earlier rentals and check whether yesterday’s count improves the 8 a.m. forecast.

  6. Logistic regression

    Turn a score into a spam probability, choose a threshold, and check the filter on new emails.

  7. Classification metrics

    Reuse the spam scores to work through the confusion matrix, choose a cutoff within a false-alarm limit, and trace the ROC curve.
