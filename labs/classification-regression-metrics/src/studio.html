Positive (P) = on time. Negative (N) = late. Positive names the class we are evaluating. It does not mean the prediction is correct. In this binary exercise, predicted P means on time (“On track”), and predicted N means late (“Likely late”). True or false tells us whether that prediction matches the actual outcome.

AUC
(wins + 0.5 × ties) / (actual P × actual N)
How 59 / 64?

Each actual on-time order (P) is paired with each actual late order (N). A win means P has the higher on-time score; a tie earns half a win.

These fixed scores rank on-time confidence; they are not calibrated probabilities.

Pair credit is from the actual-P case’s perspective: P score > N score is correctly ordered (1); P score < N score is reversed (0); equal scores receive 0.5.

Pair comparison

· Credit

1 = P score higher, correctly ordered · 0 = P score lower, reversed · ½ = tied

AUC measures discrimination: the empirical chance that a randomly paired actual-P case has a higher score than an actual-N case, with half credit for ties. It does not measure probability calibration or classification accuracy at one cutoff.

Moving only the cutoff leaves scores, labels, and their ranking unchanged, so AUC stays fixed. Changing the scores or their ranking can change AUC.

Highlight a denominator

PActual P: on timeNActual N: lateTP: correct on-track forecast, the shared numerator
Different questions, different denominators. Precision = TP / (TP + FP). Recall = TP / (TP + FN). F1 = 2TP / (2TP + FP + FN). Accuracy = (TP + TN) / all cases. ROC plots recall (TPR) against FPR = FP / (FP + TN). AUC uses the full set of on-time confidence scores, so changing only this threshold leaves AUC unchanged. The scores rank confidence in on-time arrival. Probability calibration is outside this example.

R² = 1 − SSE / SST. SSE = Σ(actual − prediction)². SST = Σ(actual − mean of actual values)². A score of 0 matches this mean baseline, 1 means zero prediction error, and a negative score means larger squared errors than the baseline. R² is not percentage accuracy. The mean here is a reference calculated from evaluation targets; it is not a fitted model trained on the evaluation data.
