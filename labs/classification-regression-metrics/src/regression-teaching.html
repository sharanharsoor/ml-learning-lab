What did we know before the hour?

One formula can count a big miss differently

MAE treats each missed rental equally. MSE squares each miss before averaging, so an error ten times larger adds a hundred times as much to the total. RMSE brings that squared scale back to rentals. Switch between the actual forecasts and a controlled comparison to see what the metrics measure.

Show explanation

MAE is 50 ÷ 5 = 10 rentals in both cases. RMSE is √(500 ÷ 5) = 10 rentals for the first set and √(2,500 ÷ 5) ≈ 22.36 rentals for the second.

How much squared error did the model save?

For these five hours, compute the model’s sum of squared errors (SSE) and the total sum of squares (SST) against a constant equal to the mean actual count. The mean minimizes squared error among constant guesses on these rows, so it is the reference in the formula for R².

That reference uses the values observed afterward. A constant forecast you could issue beforehand would instead use a mean computed from the training data.

What if every actual is the same?

In a separate illustration, three hours have actual counts 40, 40, and 40 and forecasts of 35, 40, and 45. The mean is 40, so SST is zero. The usual R² formula has a zero denominator. MAE is still (5 + 0 + 5) ÷ 3 ≈ 3.33 rentals.

How far off were we per hour?
MAE reports the average absolute miss in rentals. Use it when an extra missed rental costs the same regardless of the miss so far.
Do big misses cause extra trouble?
MSE penalizes large misses more heavily and uses rentals². RMSE applies the same penalty through MSE and reports the result in rentals.
How much squared error did we save?
R² gives the relative reduction versus the evaluation mean. R² is unitless and depends on how much the observed counts vary.
Does the forecast run high or low?
Mean residual shows average direction. Pair it with MAE or RMSE because opposite signs can cancel.
