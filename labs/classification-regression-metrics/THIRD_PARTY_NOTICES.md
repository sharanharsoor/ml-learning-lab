## UCI Wine Quality dataset

The Classification & Regression Metrics lab includes the red Wine Quality CSV and its accompanying source description for an optional fitted-model exercise.

- Dataset: [Wine Quality, UCI Machine Learning Repository](https://archive.ics.uci.edu/dataset/186/wine+quality)
- Authors: P. Cortez, A. Cerdeira, F. Almeida, T. Matos, and J. Reis
- Citation: Cortez, P., Cerdeira, A., Almeida, F., Matos, T., and Reis, J. (2009). *Wine Quality* [Dataset]. UCI Machine Learning Repository. [https://doi.org/10.24432/C56S3T](https://doi.org/10.24432/C56S3T)
- License: [Creative Commons Attribution 4.0 International, CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)
- Original download: [UCI Wine Quality archive](https://archive.ics.uci.edu/static/public/186/wine+quality.zip)

The red subset contains 1,599 original rows, eleven physicochemical input features, and a quality rating. The bundled `winequality-red.csv` is unmodified. The exercise removes exact duplicate rows in memory before splitting; it does not alter the redistributed CSV. Its quality≥7 classification target is an educational derived label, not a definition supplied by the dataset authors or a universal definition of good wine.
