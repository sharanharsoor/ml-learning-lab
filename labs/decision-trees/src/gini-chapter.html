Gini vs entropy

Entropy averages surprise. Gini impurity measures the chance that two draws from a node have different labels. In a decision tree, Gini index is another name for this node score.

Why the square?

For label k, the first draw has probability pₖ and a different second label has probability 1 − pₖ. Multiply and sum over the first label to get G = Σ pₖ(1 − pₖ) = 1 − Σ pₖ². The square is the probability of drawing the same label twice.

What changes with more labels?

A pure node gives 0 by both scores. Both scores peak when the K labels are equally common. With a uniform mix, the second draw matches whichever label came first with probability 1/K, so G = 1 − 1/K. Each label is equally surprising, so entropy is log₂(K) bits. For two labels the maxima are 0.5 and 1 bit.

Why start with Gini?

Gini uses squares and addition and avoids logarithms, so it can be cheaper to compute per candidate. It is the default in scikit-learn’s DecisionTreeClassifier. Actual training time depends on the data and implementation. If the choice matters, compare both criteria with the same validation setup and select the one that serves your metric. scikit-learn criterion reference
